Perfil

      
O site tem uma senha só, compartilhada. Os perfis
        separam o progresso de cada pessoa dentro deste aparelho.

      

        
      


      
Backup do progresso

      
Seu histórico de respostas e as redações ficam salvos
        só neste aparelho. Se você limpar os dados do
        navegador, tudo se perde — exporte de vez em quando.

      

      

        
        
        
      


      
Correção de redação por IA

      
Opcional. Cole uma chave da API do Google Gemini
        (aistudio.google.com/apikey).
        Ela fica guardada apenas neste celular e é usada
        direto do navegador para o Google — não passa por nenhum servidor deste
        site.

      
      

        
        
      

      


      
Zerar histórico

      
Apaga todas as respostas e reinicia a repetição espaçada.
        As redações não são afetadas.
